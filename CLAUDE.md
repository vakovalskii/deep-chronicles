# Хроники Глубин — заметки для Claude

Браузерная MMORPG-песочница в духе классических корейских MMO (механика своя, названия свои — никаких имён и ассетов чужих игр).
three.js r170 + Vite, без текстур: цвет вершин и простые формы. Пока одиночная игра с сохранением в localStorage.

## Запуск и релиз
- `npm install` → `npm run dev` (http://localhost:5173).
- `npm test` — юнит-тесты (`tests/unit.test.js`, node:test) → сборка → E2E в Chrome (`tests/e2e.mjs`, playwright, сам поднимает vite на 5199).
- `bash deploy/deploy.sh` — **сначала `npm test`**, потом rsync `dist/` на `root@92.255.78.10:/opt/realms/dist`. Прод: https://realms.neuraldeep.ru (nginx `deploy/nginx-realms.conf`, certbot).
- Добавил механику — добавь шаг в E2E или проверку в юнит-тесты.

## Структура
- `src/data.js` — классы, умения, предметы (грейды), мобы (дроп, агрессия, босс), магазин, таблица опыта.
- `src/world.js` — рельеф (`heightAt`), зоны (`zoneAt`), города, лес/пустошь, склеп, лабиринт катакомб (отдельная площадка x ≥ 2200, пол y = 0), препятствия-круги `obstacles`, спавны, `TELEPORTS`. Статичный мир сливается по цвету в несколько мешей.
- `src/models.js` — процедурные модели героя/мобов/NPC, `userData.anim(t, state)`.
- `src/main.js` — рендер, ввод (ЛКМ — идти/цель/атака, ПКМ — камера, колесо — зум, 1–3 умения, 4–5 зелья, Tab, F, I, M), бой, ИИ мобов (idle/wander/chase/return), NPC (торговец, хранитель врат), HUD, карты, сохранение `l2w-save1`.
- Тестовый хук `window.__g` — в dev или с `?test`.

## Принципы
- Интерфейс и комментарии — на русском.
- Далёкие мобы (> 160 м) не симулируются и не рисуются; подписи — до 20 ближайших.
- Точки телепорта и возрождения не должны попадать в препятствия (проверяется тестом).
