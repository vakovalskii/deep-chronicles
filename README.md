# Хроники Глубин

Нативная MMORPG на **Godot 4.7.2**: два города, открытая карта, зоны охоты, катакомбы, прокачка, экипировка, заточка, PvP и чат. Сервер остался на Node.js 22 + WebSocket + SQLite и управляет боем, аккаунтами и прогрессом.

Основная разработка теперь идёт в `godot/`. Браузерный клиент Three.js сохранён для совместимости.

## Запуск

```bash
npm ci
npm run dev                          # Godot → основной сервер, вход в аккаунт
npm run native:local                 # отдельная локальная игра
npm run native:verify -- --build=macos # полный конвейер + приложение
npm run native:editor                # открыть проект в редакторе
npm test                             # правила + сервер + игра в Godot
npm run native:build -- macos         # самостоятельное приложение
npm run native:build -- windows       # Windows x86_64
```

Нужен Godot 4.7.2; путь можно задать через `GODOT_BIN`. Запуск автоматически экспортирует данные из общих JS-модулей и импортирует ресурсы. Обычный запуск подключается к `wss://realms.neuraldeep.ru/ws`: войдите тем же аккаунтом, что и в браузере. Локальный режим включается только явно (`native:local`); его сохранения — `.native-run/world.db`. Токены разных серверов хранятся раздельно. Адрес другого сервера: `npm run native -- --server=wss://example.org/ws`.

Presets Android/iOS находятся в `godot/export_presets.cfg`. Для Android нужны Android SDK/JDK; для iOS — Xcode и Apple signing team. Эти цели требуют отдельной проверки на физических устройствах. Экспортные шаблоны должны соответствовать версии движка.

## Графика

Герои, 13 видов мобов, NPC, дома, храм, башни, фонтан, деревья и камни используют текстурированные GLB. У персонажей есть скелет и клипы движения/боя. Модели размещаются поверх прежней карты с теми же серверными координатами и препятствиями. Земля смешивает шесть рисованных материалов; свет и окружение доступны в сцене Godot.

- `godot/assets/manifest.json` — реестр моделей; `godot/assets/` — исходные игровые ресурсы.
- `art/concepts/` и [art/README.md](art/README.md) — концепты, происхождение и генерация.
- `npm run native:art -- <id>` — подготовка завершённого результата TRELLIS через Blender.
- `npm run native:gallery -- --models=warrior,mage,wolf` — контрольный рендер моделей.
- `godot/generated/` пересоздаётся через `npm run native:assets` и не редактируется вручную.

Повторяемая сборка, проверки клиента с сервером и отчёты: [docs/NATIVE_PIPELINE.md](docs/NATIVE_PIPELINE.md).

Полный порядок работы для следующих агентов: [AGENTS.md](AGENTS.md). Подробности серверного протокола и старого клиента: [CLAUDE.md](CLAUDE.md).

План страницы скачивания, статуса сервера и выпуска обновлений: [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md). Направление интерфейса: [docs/UI_STYLE.md](docs/UI_STYLE.md).

## Управление

WASD или ЛКМ — идти; ПКМ/два пальца — камера; колесо/щипок — масштаб; 1–3 — умения; 4–5 — зелья; Tab — цель; F — атака; E — разговор; I — сумка; C — герой; K — умения; M — карта; Esc — меню; V — камера; F11 — полный экран; Enter — чат. На телефоне есть джойстик и кнопки. Перетаскивание и двойной щелчок работают в инвентаре. `/w Имя текст` — личное сообщение, `/r` — ответ.
