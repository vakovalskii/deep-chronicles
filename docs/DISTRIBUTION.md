# Распространение нативного клиента

Браузерная игра закрыта по решению пользователя от 18 сентября 2026. Сайт https://realms.neuraldeep.ru — страница скачивания клиентов и проверки онлайна. Аккаунты и SQLite-прогресс сохраняются; запуск игры происходит в Godot-приложении.

## Один воспроизводимый выпуск

```
npm ci
npm run native:verify -- --release
npm run deploy -- --verified
```

Конвейер проверяет сервер и настоящий клиент, собирает обе настольные цели, упаковывает EXE, строит сайт и проверяет его headless-браузером с отдельным Node-сервером. Хеши входов и результатов защищают релиз от изменений после проверки. Настройка Godot/templates/Node — в NATIVE_PIPELINE.md; упаковка Windows использует Python 3. Релиз обеих настольных платформ выполняется на macOS, поскольку macOS-пакет распаковывается через `ditto`.

- Windows: `godot/builds/windows/khroniki-glubin-windows.zip` → `/downloads/khroniki-glubin-windows.zip`. Внутри один самостоятельный EXE со встроенными ресурсами, README и SHA-256 EXE.
- macOS: `godot/builds/macos/Хроники Глубин.zip` → `/downloads/khroniki-glubin-macos.zip`. Приложение universal arm64/x86_64.
- `dist/release.json`: commit исходников, размер и SHA-256 обоих ZIP. На странице отображаются те же значения.
- Статус использует анонимное приветствие WebSocket `/ws`; не входит в аккаунт и не увеличивает число игроков. Проверка каждые 30 секунд.
- Серверный релиз сохраняет прежний код и SQLite, не загружает локальные аккаунты. Старые файлы браузерной игры удаляются из `dist/` при сборке и при `rsync --delete`.

## Что ещё не готово

Это тестовые сборки. Windows экспортируется и проверяется по содержимому архива, но запуск EXE на настоящей Windows требует отдельной машины. macOS использует текущую локальную подпись, публичная Apple-нотаризация не настроена; Windows-подписи издателя тоже нет. Android/iOS имеют presets, но пока не публикуются — нужны SDK, ключи и тесты устройств.

Автоматического обновлятора нет: обновление через новый ZIP. Следующий этап — версионированный каталог релизов и подписанный манифест, загрузка во временную папку, проверка хеша/подписи, переключение версии с откатом. Сейчас не выдавать план обновлятора за работающую функцию.
