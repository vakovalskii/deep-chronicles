# Публичная разработка полного проекта

Полный текущий проект находится в публичном [deep-chronicles](https://github.com/vakovalskii/deep-chronicles), основная ветка `server-authoritative`. 18.09.2026 пользователь прямо попросил сделать этот репозиторий публичным; GitHub visibility изменена с PRIVATE на PUBLIC. Это заменяет предыдущий режим приватной разработки. GitHub открывает `server-authoritative` по умолчанию. Прежняя `main` сохранена: у неё другая история, force push не применялся.

В рабочем каталоге:

| Remote | Назначение |
|---|---|
| `origin` | основной публичный `vakovalskii/deep-chronicles` |
| `oss` | прежний публичный `vakovalskii/khroniki-glubin` |

`server-authoritative` отслеживает `origin/server-authoritative`; `remote.pushDefault=origin`. Обычный push отправляет полный проект в основной публичный репозиторий. Старый `oss` остаётся архивом: не дублировать туда релизы автоматически. Лицензия и сведения об источниках ассетов сохранены.

## Проверка и выпуск

Текущее направление — [UE5](UE5_MIGRATION.md), пока выбирается машина и сохраняется существующий Godot. Сохранение checkpoint и планов в Git не является выпуском на сервер/сайт. Последние изменения охоты/пати имеют незакрытый нативный тест; точное состояние в [CURRENT_TASKS.md](CURRENT_TASKS.md). Не выдавать отправленный коммит или начавшийся CI за готовую новую сборку.

После `npm ci` и установки Godot 4.7.2/templates: `npm run native:verify -- --release`, затем `npm run deploy -- --verified`. Для установки закреплённого движка есть `npm run native:bootstrap`: он выводит путь для переменной `GODOT_BIN`; в GitHub Actions устанавливает её автоматически. Полный выпуск macOS+Windows выполняется на macOS.

Push запускает `.github/workflows/native.yml` на Windows и macOS. Каждый runner собирает собственный пакет, выполняет встроенный тест упакованного приложения и проверяет основной сервер без входа в аккаунт. Рабочие БД и секреты не участвуют. Результаты — в Actions artifacts.

## OSS

**Разделение запросов:** «оср бокс / оср пайп» означает OCR-сервер распознавания документов, временно занятый TRELLIS; восстановление описано в `OCR_BOX.md`. Отдельным последующим сообщением пользователь разрешил публичность всего deep-chronicles. Видимость и содержимое старого khroniki-glubin не менялись; опубликованные версии/лицензии не удалялись.

Ранее подготовленный, но **не запрошенный пользователем и не опубликованный**, вариант серверного OSS-экспорта:

```sh
bash tools/sync-oss.sh --server
```

Команда берёт только разрешённые серверные файлы и общие правила из **HEAD**, создаёт самостоятельный package/lockfile/README/CI и запускает тесты в `.native-run/oss-server`. Godot, модели, тексты внутренней памяти, `.env`, базы и история основного репозитория в этот отдельный экспорт не входят. Для публикации полного проекта такой экспорт не нужен: основной репозиторий уже открыт.

Флаг `--push` публикует подготовленный и проверенный снимок отдельным коммитом через временный clone публичного репозитория. Использовать его после решения пользователя о серверной OSS-публикации. Старый сценарий копирования всего checkout отключён.

Автообновление клиента описано отдельно: [AUTO_UPDATE.md](AUTO_UPDATE.md). Наличие сайта скачивания не означает наличие установленного лаунчера.
