# Приватная разработка и отдельная публикация сервера

Полный текущий проект находится в приватном [deep-chronicles](https://github.com/vakovalskii/deep-chronicles), основная ветка `server-authoritative`. GitHub открывает эту ветку по умолчанию. Прежняя `main` сохранена: у неё другая история, force push не применялся.

В рабочем каталоге:

| Remote | Назначение |
|---|---|
| `origin` | приватный `vakovalskii/deep-chronicles` |
| `oss` | прежний публичный `vakovalskii/khroniki-glubin` |

`server-authoritative` отслеживает `origin/server-authoritative`; `remote.pushDefault=origin`. Обычный push отправляет разработку в приватный репозиторий. Не отправлять полный клиент через `git push oss`.

## Проверка и выпуск

После `npm ci` и установки Godot 4.7.2/templates: `npm run native:verify -- --release`, затем `npm run deploy -- --verified`. Для установки закреплённого движка есть `npm run native:bootstrap`: он выводит путь для переменной `GODOT_BIN`; в GitHub Actions устанавливает её автоматически. Полный выпуск macOS+Windows выполняется на macOS.

Push запускает `.github/workflows/native.yml` на Windows и macOS. Каждый runner собирает собственный пакет, выполняет встроенный тест упакованного приложения и проверяет основной сервер без входа в аккаунт. Рабочие БД и секреты не участвуют. Результаты — в Actions artifacts.

## OSS

Состав публичного репозитория **ещё ожидает уточнения пользователя**: было пожелание закрыть новую версию и затем вернуть сервер под OSS-конвейер. Видимость и содержимое публичного репозитория в этой итерации не изменялись. Старые опубликованные версии/лицензии не удалялись.

Подготовленный путь для варианта «сервер открытый, полный проект приватный»:

```sh
bash tools/sync-oss.sh --server
```

Команда берёт только разрешённые серверные файлы и общие правила из **HEAD**, создаёт самостоятельный package/lockfile/README/CI и запускает тесты в `.native-run/oss-server`. Godot, модели, тексты внутренней памяти, `.env`, базы и история приватного репозитория в экспорт не входят.

Флаг `--push` публикует подготовленный и проверенный снимок отдельным коммитом через временный clone публичного репозитория. Использовать его после решения пользователя о серверной OSS-публикации. Старый сценарий копирования всего checkout отключён.

Автообновление клиента описано отдельно: [AUTO_UPDATE.md](AUTO_UPDATE.md). Наличие сайта скачивания не означает наличие установленного лаунчера.
