# Серверная добыча

`src/loot.js` задаёт радиус подбора 3 м, защиту владельца 20 с, исчезновение через 5 минут. Экспортёр включает те же значения в `UI_RULES.loot` для Godot. Версия сохранений не меняется.

Убийство сразу даёт опыт, SP и увеличивает счётчик убийств. Автолут включён по умолчанию и хранится в серверном профиле; `{t:"autoloot", enabled:bool}` меняет настройку с сохранением. При автолуте `creditLoot` выдаёт монеты и вещи победителю и сохраняет профиль сразу. При сбое выдача откатывается, награда остаётся на земле. При отключённом автолуте монеты и предметы из таблицы моба создаются в `server/sim/loot.js`, разлетаются вокруг тела с учётом препятствий. Владелец определяется существующим правилом максимального урона. Привязка к ключу аккаунта сохраняет право после переподключения.

- `hi.features.groundLoot:1`, `autoloot:1`, `progression:1` — возможности сервера.
- `kill` несёт начисленные `xp` и `sp`; `ground:false` вместе с событиями `pickup` означает успешный автолут. Поле `pickup.id` при автолуте пустое, потому что объекта на земле не было.
- `snap.g` — полный список добычи в области видимости. Поля: `id`, `item` (`coins` или ID предмета), `n`, `x/y/z`, `ownerName`, `protectedUntil`, `expiresAt`, `available`. Приватный ключ аккаунта не передаётся.
- Клиент отправляет только `{t:"pickup", id}`. Сервер проверяет существование, срок, смерть игрока, расстояние и право. Клиентские количество, тип и награда игнорируются.
- Объект удаляется синхронно, выдаётся награда и сразу сохраняется профиль в SQLite. Если сохранение не удалось, награда откатывается, дроп возвращается на землю. Повторный запрос не выдаёт повторную награду.
- `ev` с `k:"pickup", id, item, n` подтверждает подбор; `you` обновляет сумку/кошелёк; ближайший `snap.g` убирает предмет у всех наблюдателей. Ошибка: `{t:"pickup_err", id, reason}`.
- `kill.ground:true` означает, что указанное количество монет лежит на земле. Клиент не должен рисовать автоматическое зачисление.

Поднятые вещи и монеты хранятся в профиле. Неподнятая добыча живёт в памяти текущего процесса: при рестарте мира исчезает. SIGTERM/SIGINT сохраняют активные профили перед выходом. Дроп вещей в существующей PvP-механике пока остаётся отдельным правилом, эта миграция меняет награды мобов.

Godot: `ground_loot.gd`, синхронизация и подход в `main.gd`, кошелёк/фильтры в `hud.gd`. Браузерная игра больше не поддерживается. Постоянная кнопка «Поднять · Z» и назначаемая ячейка «Дроп» доступны в Godot. Изолированный DEV_CMD допускает `dev.drop` для тестового предмета и 17 монет; на основном сервере команда выключена.

Проверки: unit — время/право/дальность/смерть/повтор; server — два WS-клиента, подделка количества, отказ чужому и далёкому, сохранение; native — настоящее убийство, смерть, клик по монетам/предмету, подход, кошелёк, исчезновение у второго клиента.
