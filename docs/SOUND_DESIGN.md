# Звук и музыкальное сведение

Второй проход от 18.09.2026 заменяет 13 синтетических WAV. Банк содержит 67 файлов: записи шагов/взмахов/попаданий, голоса существ, готовые эффекты магии, три музыкальные темы и петлю ветра. Утверждение о «13 собственных звуках» относится только к прошлому выпуску.

| Источник | Использование | Лицензия |
|---|---|---|
| [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) | Шаги по траве/камню, удары по телу/камню/дереву | CC0 |
| [Kenney RPG Audio](https://kenney.nl/assets/rpg-audio) | Монеты | CC0 |
| [rubberduck — 80 RPG SFX](https://opengameart.org/content/80-cc0-rpg-sfx) | Магия, металл, боль/смерть существ | CC0 |
| [artisticdude — RPG Sound Pack](https://opengameart.org/content/rpg-sound-pack) | Взмахи, звери, насекомые, нежить, тяжёлые существа | CC0 |
| [cynicmusic — Town Theme RPG](https://opengameart.org/content/town-theme-rpg) | Город: арфа, духовые, струнные; cynicmusic.com / pixelsphere.org | CC0 |
| [TinyWorlds — Forest Ambience](https://opengameart.org/content/forest-ambience) | Спокойная музыкальная тема путешествия, не полевые записи | CC0 |

`godot/assets/audio/manifest.json` фиксирует авторов, страницы, прямые источники, SHA-256 архивов/файлов, выбранные элементы архивов и громкости. Ресурсы коммитятся; игра и CI ничего не скачивают. WAV artisticdude преобразованы в mono PCM16 с удалением постоянной составляющей и пиком −6 dB; алгоритм на Python stdlib детерминирован. OGG/MP3 сохранены без перекодирования. Это не музыка/звуки Lineage II.

## Микшер

- Четыре независимых сохраняемых регулятора: Master, Effects, Music, Ambience. Музыка не глушит эффекты при изменении своего регулятора.
- Музыкальные уровни выровнены по измеренному integrated loudness до −19 LUFS перед пользовательской громкостью. Исходная тема TinyWorlds очень тихая (−46.21 LUFS), поэтому ей нужен +27.2 dB; Town −13.05 → −5.9 dB, Hope −9.90 → −9.1 dB. Нормализованный коэффициент перехода отделён от усиления дорожки: тихий исходник не должен растягивать переход на минуту.
- Два музыкальных проигрывателя, переход около 2.2 с. Реальная собственная атака/получение урона/замах моба запускают боевую тему; она удерживается 6 с после последнего события. В городе музыка остаётся спокойной. Во время удара кратковременное приглушение ещё на 5 dB, затем плавное восстановление.
- 24 пространственных голоса эффектов, дальность 55 м, небольшая вариация высоты, разные семплы по кругу без соседнего повтора. Шаги считаются по реальному пройденному расстоянию и длине шага анимации; стояние/каст/телепорт не создают шагов.
- Master: AudioEffectHardLimiter, потолок −1 dB. Реальный рендерный тест снимает выход AudioEffectCapture и проверяет ненулевой конечный сигнал и отсутствие перегруза. Это техническая проверка микса, а не замена художественного прослушивания на разных устройствах.

## Воспроизведение

- `npm run native:audio -- --check` — офлайн-проверка всех файлов и ссылок cue.
- `npm run native:audio -- --fetch` — восстановление из закреплённых источников; Python 3, без API-ключей.
- `npm run native:audio -- --analyze` — анализ каждого файла через ffmpeg: `.native-run/audio-audit.json` (LUFS/true peak/LRA).
- `npm run test:native` — реальный сервер, рендер, декодирование банка, варианты ударов, шаги, микшер, музыка/ducking, сохранение настроек, очистка при logout.
- `npm run native:local` — интерактивное прослушивание с локальным сервером. OCR GPU не используется.
