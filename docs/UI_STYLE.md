# Интерфейс: классическая MMORPG в Godot

Ориентир пользователя от 18.09.2026 — компактная компоновка Lineage II из трёх присланных скриншотов. Название, персонажи, предметы и оформление принадлежат «Хроникам Глубин». Игровые окна — настоящие Godot Control, работающие с сервером.

- Цвета: угольно-коричневые полупрозрачные панели, тонкий серо-золотой контур, прямые углы; небольшие тёмно-синие кнопки. Без крупных скруглённых карточек.
- Статус слева сверху: имя/уровень, красная HP, синяя MP, фиолетовая EXP, зона и онлайн. Баффы рядом.
- Цель сверху по центру: имя и уровень, HP, подсказка атаки. В мире — толстое тёпло-красное кольцо, золотая стрелка и выделенное имя. Один клик выбирает, повторный клик/F атакует; Q переключает, Tab/I открывает сумку.
- Справа сверху — миникарта с живыми мобами, игроками, NPC и выбранной целью.
- Слева снизу — чат, вкладки внизу, строка ввода. Внизу по центру — десять компактных ячеек действий. Справа снизу — персонаж, сумка, карта и меню.
- Сумка — окно справа: на ПК экипировка и вращаемый 3D-персонаж слева, сетка вещей справа, подробности выбранной вещи и кошелёк снизу. На touch компоновка вертикальная с более крупными ячейками. Окна можно перетаскивать за заголовок; положение сохраняется в текущем сеансе при обновлении серверных данных.
- В окне персонажа — вращаемый 3D-предпросмотр текущего героя с реальным оружием и экипировкой; ниже характеристики.
- Вход — название мира над компактной формой. Создание включает выбор класса и настоящий 3D-предпросмотр. Сервер можно изменить, раскрыв поле.
- Touch использует увеличенные кнопки и джойстик. Проверка на десктопе не является проверкой Android/iOS.

Файлы: `hud.gd`, `chat_panel.gd`, `window_frame.gd`, `character_preview.gd`, `actor.gd`, `main.gd`. Предпросмотр нового героя экспортируется из `server/sim/player.js::newChar`, существующего — из серверного профиля. Визуальные проверки: `npm run test:native` и `npm run test:native -- --touch`, включая скриншоты `login.png`, `create-character.png`, `character.png`, `inventory.png`, `target-selected.png`.

Дополнительные изображения и выводы: [C4_RESEARCH.md](C4_RESEARCH.md). Кошелёк и вес закреплены под содержимым сумки; фильтры/поиск/сортировка работают с исходными индексами серверного инвентаря. Механика подбора: [GROUND_LOOT.md](GROUND_LOOT.md).

## Основа следующего интерфейса — четыре новых референса пользователя

Пользователь явно сказал «Надо взять это за основу» после четырёх скриншотов с крупным планом чата, храмом, целью и открытой сумкой. Это основной ориентир компоновки и плотности, а не требование подделать конкретную версию C4. Копии для локального сравнения: `.native-run/ui-user-references/reference-{1..4}.png`; изображения чужой игры не входят в игровые ресурсы.

- Тонкая бронзовая двойная рамка с небольшими уголками, угольно-оливковый полупрозрачный фон, сдержанные выпуклые кнопки. Новые SVG в `godot/assets/ui/` нарисованы для проекта и редактируются как текст, без внешних скачиваний.
- Небольшая карточка HP/MP/EXP сверху слева, узкая карточка цели; мир занимает большую часть экрана. Не увеличивать панели до широких веб-карточек.
- Невысокий системный журнал НАД обычным чатом; вкладки и строка ввода снизу. Торг — приглушённый лиловый, ближний — бирюзовый, награды — жёлтый. Без повторяющегося `[Торг]` перед каждым именем; канал различим по вкладке и цвету. Существующие настройки размера текста/высоты сохраняются.
- Инвентарь: 12 слотов вокруг действующего 3D-героя, предметы в шестиколоночной сетке; количество и заточка наложены на иконку. Пустые места экипировки обозначаются собственными силуэтами. Реальное перетаскивание отправляет команду серверу; предпросмотр не рассчитывает результат экипировки.
- Панель навыков компактнее, системные действия получили собственные иконки; атака/подбор/цель, автолут и замок остаются доступны. Не показывать несуществующие группы/кланы/квесты работающими вкладками.

Это проход по интерфейсу. Архитектура и освещение храма на референсах пока не перенесены в игровой мир. Следующий художественный проход: цельный участок города/руин, более выразительные силуэты, локальный свет, защита камеры от перекрывающих её крон (обнаружено при визуальной проверке боя в лесу).
