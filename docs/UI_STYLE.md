# Интерфейс: классическая MMORPG в Godot

Ориентир пользователя от 18.09.2026 — компактная компоновка Lineage II из трёх присланных скриншотов. Название, персонажи, предметы и оформление принадлежат «Хроникам Глубин». Игровые окна — настоящие Godot Control, работающие с сервером.

- Цвета: угольно-коричневые полупрозрачные панели, тонкий серо-золотой контур, прямые углы; небольшие тёмно-синие кнопки. Без крупных скруглённых карточек.
- Статус слева сверху: имя/уровень, красная HP, синяя MP, фиолетовая EXP, зона и онлайн. Баффы рядом.
- Цель сверху по центру: имя и уровень, HP, подсказка атаки. В мире — толстое тёпло-красное кольцо, золотая стрелка и выделенное имя. Один клик выбирает, повторный клик/F атакует; Tab переключает.
- Справа сверху — миникарта с живыми мобами, игроками, NPC и выбранной целью.
- Слева снизу — чат, вкладки внизу, строка ввода. Внизу по центру — десять компактных ячеек действий. Справа снизу — персонаж, сумка, карта и меню.
- Сумка — узкое окно справа: экипировка сверху, сетка вещей ниже, подробности выбранной вещи. Окна можно перетаскивать за заголовок; положение сохраняется в текущем сеансе при обновлении серверных данных.
- В окне персонажа — вращаемый 3D-предпросмотр текущего героя с реальным оружием и экипировкой; ниже характеристики.
- Вход — название мира над компактной формой. Создание включает выбор класса и настоящий 3D-предпросмотр. Сервер можно изменить, раскрыв поле.
- Touch использует увеличенные кнопки и джойстик. Проверка на десктопе не является проверкой Android/iOS.

Файлы: `hud.gd`, `chat_panel.gd`, `window_frame.gd`, `character_preview.gd`, `actor.gd`, `main.gd`. Предпросмотр нового героя экспортируется из `server/sim/player.js::newChar`, существующего — из серверного профиля. Визуальные проверки: `npm run test:native` и `npm run test:native -- --touch`, включая скриншоты `login.png`, `create-character.png`, `character.png`, `inventory.png`, `target-selected.png`.
