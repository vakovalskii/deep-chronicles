# Решение: основной клиент — нативный Godot

**Дата:** 2026-09-18 · **Статус:** историческое решение; направление заменено [переходом на UE5](docs/gitmark/decisions/2026-09-18-unreal-client.md). Godot пока остаётся рабочим клиентом. Текст ниже описывает состояние на момент первоначального выбора, а не актуальный план/релиз.

## Контекст

Игра жила как браузерная: three.js r170 + Vite, клиент в [`src/main.js`](src/main.js) (1406 строк),
раздача статики nginx-ом. Сервер уже был авторитетным, а значит правила боя и мира лежат
в общих модулях `src/*.js`, которые импортирует и клиент, и сервер.

Упирались в картинку и ввод: браузер ограничивает работу с моделями, освещением и
шейдерами, а UI в духе классической L2 (см. [UI_STYLE](docs/UI_STYLE.md)) требует
нормальных окон, перетаскивания и 3D-превью персонажа.

> В памяти проекта есть более ранняя заметка «остаёмся на three.js, Godot ломает общий код
> клиента и сервера». Она **устарела**: решение пересмотрено 2026-09-18, а опасение про общий
> код снято экспортом (см. ниже).

## Решение

1. Основной клиент — **Godot 4.7.2**, каталог [`godot/`](godot/). `npm run dev` запускает именно его.
2. **Сервер и общие правила не переписываем.** `server/` и `src/{data,stats,sim,pvp,world-core}.js`
   остаются единственным источником истины по прогрессу, бою и миру.
3. Мост между мирами — [`tools/godot/export.mjs`](tools/godot/export.mjs): он импортирует
   JS-модули в Node и запекает из них `godot/generated/` (мир, каталог предметов, высоты,
   актёры в glTF, `UI_RULES`). Godot не дублирует правила, а читает запечённые данные.
4. Браузерный клиент **не удаляем**, но переводим в легаси: он собирается `npm run build:web`
   и проверяется `npm run test:web`, из основного `npm test` выведен.

## Последствия

- Плюс: общий код клиента и сервера уцелел — правила по-прежнему в одном месте и покрыты
  юнит-тестами; Godot получает их данными, а не копипастой.
- Плюс: появилась воспроизводимая приёмка нативной сборки — `npm run native:verify`.
- Минус: web-клиент больше не ловится основным прогоном тестов; регрессии в нём заметны
  только при явном `npm run test:web`.
- Минус (открытый хвост): `npm run deploy` до сих пор выкладывает **веб**-`dist/`, а не
  нативные сборки. Раздача нативных билдов пока только план — [DISTRIBUTION](docs/DISTRIBUTION.md).
- Минус: [`CLAUDE.md`](CLAUDE.md) ниже шапки описывает старый веб-мир и противоречит сам себе;
  рабочая инструкция — [`AGENTS.md`](AGENTS.md).

## Альтернативы

- **Остаться на three.js** — отклонено: потолок по картинке и UI.
- **Переписать сервер на Godot/GDScript** — отклонено: потеряли бы отлаженные авторитетные
  правила, тесты и общий код; экспорт данных решает задачу дешевле.
