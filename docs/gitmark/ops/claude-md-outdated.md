# Грабли: CLAUDE.md разъезжается с AGENTS.md

## Что было

После переезда на Godot [`CLAUDE.md`](CLAUDE.md) поправили только сверху — блоком цитат
«основной клиент Godot, не считайте Three.js основным». Всё ниже 13-й строки осталось
нетронутым веб-документом и прямо противоречило шапке:

| было написано | как на самом деле |
|---|---|
| «Браузерная MMORPG… three.js r170 + Vite» | основной клиент нативный, `godot/` |
| `npm run dev` = WS-сервер + Vite на :5173 | `npm run dev` запускает **Godot**; браузер — `npm run dev:web` |
| `npm test` = юниты + сборка + E2E в Chrome | `npm test` = юниты + сервер + **нативный** smoke |
| релиз = rsync `dist/`, и всё | это правда, но выкладывается легаси-клиент; про `native:build`/`native:verify` не было ни слова |

Чем опасно: агент или новый человек чинит браузерный клиент, запускает `npm run dev` и
удивляется Godot, а `npm test` считает сломанным, не увидев E2E.

## Как закрыто (2026-09-18)

Синхронизировать два файла руками — значит однажды снова их разъехать, поэтому файл теперь
**один**: `CLAUDE.md` — симлинк на `AGENTS.md`.

1. Уникальное содержимое `CLAUDE.md` (описание проекта, релиз, открытый код, таблица
   «кто что считает», структура каталогов, протокол, принципы, «дальше») перенесено
   в `AGENTS.md` — разделы после «Данные и внешние системы».
2. Устаревшее выброшено или переписано: запуск через Vite, E2E в Chrome в составе `npm test`,
   «браузерная MMORPG» во вступлении.
3. `rm CLAUDE.md && ln -s AGENTS.md CLAUDE.md`. Git хранит это как симлинк (`typechange`).

## Правило на будущее

Единственный источник — **`AGENTS.md`**; править нужно только его. Не превращайте `CLAUDE.md`
обратно в обычный файл: вторая копия немедленно начнёт отставать. Справочные подробности
(протокол, правила, конвейеры) уносите в базу знаний, чтобы не заводить третью копию правды.
