# Переезд клиента на Godot: состояние на 2026-09-18

История действующего клиента. Последнее направление пользователя — [UE5](docs/gitmark/plans/unreal-migration.md); актуальная очередь и результаты проверок — [CURRENT_TASKS](docs/CURRENT_TASKS.md).

Ветка `server-authoritative`. Решение и его обоснование —
[отдельный документ](docs/gitmark/decisions/2026-09-18-native-godot-client.md);
здесь только «что уже есть, что в работе, что не сделано».

## Сделано

Коммит `5f84e76 Migrate primary client to Godot with textured world and restored UI` —
основной переезд: проект Godot, текстурированный мир, восстановленный интерфейс, концепты,
ассеты, документы в `docs/`.

- Клиент на Godot 4.7.2 играбелен против боевого сервера; `npm run dev` запускает именно его.
- Мост `tools/godot/export.mjs` запекает правила и мир из JS — общий код не продублирован.
- Авторитет сервера сохранён; общие правила расширяются вместе с нативным клиентом.
- Нативный smoke `godot/tests/smoke.gd` покрывает вход, бой, сумку, лавку, заточку, чат,
  переподключение по токену и смену класса.

## Последующие завершённые проходы

- Строгий UI, цель, восстановленные меню, серверная синхронизация и крепление оружия.
- Серверный наземный дроп, смерть животных и сумка с фильтрами/кошельком.
- По новым требованиям: системный журнал отдельно над чатом, фильтры, прокрутка без движения камеры; масштаб миникарты; настраиваемая панель и постоянная кнопка подбора.
- Автолут с сохранением, SP и изучение рангов, гарантированное изготовление и B-экипировка для обоих классов. Собственная шкала 8/18/25, не исторические уровни C4.
- Рельеф/декорации привязаны к одинаковой сетке 4 м. Прежняя сетка 10 м давала зазоры.
- Пользователь окончательно закрыл браузерную игру. На сайте — ZIP нативных клиентов и онлайн. Конвейер `native:verify -- --release` включает сервер, Godot, обе сборки, страницу скачивания.

Текущее состояние задач и подтверждение релиза: [CURRENT_TASKS](docs/CURRENT_TASKS.md). Чужая правка `tools/trellis/texture.py` не относится к этим изменениям.
