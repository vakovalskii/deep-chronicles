# Нативный клиент на Godot

> Актуализация 18.09.2026: браузерная игра закрыта. Клиент — только Godot; сайт `site/` — ZIP и онлайн. SP/ранги, автолут и крафт описаны в [PROGRESSION](docs/PROGRESSION.md), протоколе и AGENTS.md. Отдельный системный журнал, панель действий, масштаб миникарты и точная привязка к рельефу проверяются native smoke. Полный релиз: `native:verify -- --release`, затем `deploy -- --verified`.


Godot **4.7.2**, каталог [`godot/`](godot/). С 2026-09-18 — основной клиент игры.
Отвечает за камеру, ввод, отрисовку, эффекты и предсказание собственной ходьбы;
всё, что влияет на прогресс, спрашивает у сервера.

Запуск: `npm run dev` (прод-сервер) · `npm run native:local` (свой мир) · `npm run native:editor`.

## Точка входа и дерево сцены

`project.godot` → `res://scenes/main.tscn` → `main.gd::_ready()` (`godot/scripts/main.gd:50-76`).
Сцен всего две — почти всё дерево собирается кодом:

```
Chronicles (main.gd)
├─ World (scenes/world.tscn + world.gd) — чанки рельефа, вода, MultiMesh-декорации, GLB-постройки, порталы
├─ Camera3D (fov 55, far 1600)
├─ Actor × N — NPC из GameData.world.npcs
├─ selection / marker (кольца), target_arrow (Label3D «▼»)
├─ Hud (CanvasLayer, hud.gd)
│    login_panel + game_ui: статус, бафы, панель цели, миникарта (map.gd),
│    чат (chat_panel.gd), 10 слотов действий, командная строка, джойстик, окна
├─ Hero (actor.gd) — создаётся по `authok`
└─ Actor × N — мобы и другие игроки
```

Автозагрузки (`project.godot:11-13`): `GameData` → `scripts/data.gd`, `Network` → `scripts/network.gd`.
После сборки сцены `main.gd:76` печатает **`NATIVE_READY`** — по этой строке ждёт нодовая обвязка.

Флаги запуска: `--quick-start`, `--resume`, `--capture=<png>` (`main.gd:51-54`),
`--server=`, `--test-mode` (`network.gd:21-23`), `--touch` (`hud.gd:66`).

Важное внутри:

- `main.gd:_message()` (`:97-176`) — единственный разбор сообщений сервера;
  `_event()` (`:181-225`) превращает пачку `ev` в строки лога, цифры урона, кольца и снаряды.
- `main.gd:_process()` (`:232-268`) — предсказание своей ходьбы, интерполяция чужих
  на `now − clock_offset − 150 мс`, отправка `st` 10 раз в секунду, обновление UI 5 раз.
- `main.gd:pick()` (`:481-505`) — сначала выбор ближайшего актёра в экранных координатах,
  потом марш луча в 400 шагов по полю высот с 8 уточнениями делением пополам.
- `hud.gd` наружу отдаёт ровно два сигнала: `action(kind, value)` и `login_requested(data)` —
  геймплейных вызовов сети в нём нет. Кнопки помечены `set_meta` (`"buy"`, `"teleport"`,
  `"item_action"`…) специально, чтобы по ним кликал `tests/smoke.gd`.
- Синхронизация часов односторонняя: минимум наблюдённой разницы `snap.ts` с локальным
  временем, подтягивается вверх лерпом 0.02 (`main.gd:140-142`).

## Правила на клиенте — это зеркало, а не источник

[`data.gd`](godot/scripts/data.gd) повторяет часть правил (статы, заточка, цена продажи,
внешний вид) **только чтобы рисовать предпросмотр**. Порядок суммирования «сначала сумка,
потом экипировка» сохранён специально, чтобы совпадало округление с JS (`data.gd:90`).
Считает всё равно сервер; расхождение ловится экспортированными фикстурами в `smoke.gd`.

## Сеть

`WebSocketPeer` напрямую, без высокоуровневого мультиплеера Godot. Сигналы: `message`,
`status_changed`, `connected`.

- Адрес по умолчанию `wss://realms.neuraldeep.ru/ws` (`network.gd:6`), перебивается
  `--server=` (его всегда передаёт `tools/godot/run.mjs`) или полем в панели входа.
  Схема только `ws://`/`wss://`.
- Токены — `user://sessions.json`, карта `endpoint → {endpoint, name, token}`, поэтому
  **токены разных серверов не смешиваются**; старый одиночный `session.json` мигрируется
  и удаляется. `--test-mode` отключает сохранение полностью.
- Жизненный цикл (`network.gd:47-81`): опрос каждый кадр, таймаут соединения 15 с, тишины —
  35 с, переподключение с ростом паузы 1 с → ×2 → потолок 15 с; при `APPLICATION_RESUMED`
  реконнект, если пакетов не было > 10 с. Входной буфер поднят до 1 МиБ.

Полный список кадров — [Протокол](docs/gitmark/reference/protocol.md).

## Тесты

Четыре `SceneTree`-скрипта в [`godot/tests/`](godot/tests):

| скрипт | команда | что проверяет |
|---|---|---|
| `smoke.gd` (237) | `npm run test:native` | главный интеграционный прогон против настоящего сервера на случайном порту |
| `weapons.gd` (48) | `npm run native:weapons` | хват оружия в шести позах: кость `DEF-hand.R`, совпадение `handle_center` с рукоятью, соосность клинка и ладони (`dot > 0.999`) |
| `server_probe.gd` (22) | `npm run native:probe` | только соединение с боевым сервером и кадр `hi`; без входа в аккаунт |
| `gallery.gd` (26) | `npm run native:gallery` | не тест: рендер витрины моделей в PNG для художественной приёмки |

`smoke.gd` отказывается работать без `--test-mode --server=… --artifacts=…` (`smoke.gd:40-41`)
и печатает `NATIVE_TEST_RESULT checks=N failures=N`. Внутри, по порядку: 48 фикстур статов
против JS-правил, счётчики контента (155 спавнов, 3251 препятствие, ≥2000 расстановок моделей),
совпадение высоты рельефа, непроходимость фонтана, наличие скелета и клипов у каждого рига,
вход и регистрация, снапшоты мобов, вместимость всех 10 окон в экран (со скриншотом каждого),
ходьба джойстиком без единого `fix`, покупка, надевание, заточка, продажа стека по серверной цене,
баф, телепорт, метки на миникарте, второй «сырой» WebSocket-клиент для проверки общего и личного
чата, переподключение по токену с сохранением уровня, и смена класса на мага с проверкой каста и
подмены модели оружия.

## Ассеты

`godot/assets/` — авторский исходник (коммитится), `godot/generated/` — расходный мост,
пересобирается `npm run native:assets`. Материалы и модели ищутся «сначала в `assets/`,
потом в `generated/`» (`world.gd:47`, `actor.gd:42`). Подробно —
[Конвейер графики](docs/gitmark/reference/art-pipeline.md).

## Добыча и инвентарь

Животные проигрывают смерть и оставляют тело; `ground_loot.gd` рисует серверный дроп. Клик подводит и подбирает, Z/9 выбирает ближайший предмет. `snap.g` удаляет поднятое у всех клиентов. Кошелёк закреплён внизу сумки; поиск/фильтры/сортировка сохраняют серверные индексы. См. [GROUND_LOOT](docs/GROUND_LOOT.md), [C4_RESEARCH](docs/C4_RESEARCH.md). Native smoke теперь содержит 70 проверок и скриншоты смерти/дропа/кошелька, в том числе для `--touch`.
