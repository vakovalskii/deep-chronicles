# Браузерный клиент (легаси)

three.js r170 + Vite. До 2026-09-18 был основным клиентом, сейчас — легаси:
основной клиент [нативный, на Godot](docs/gitmark/services/godot-client/README.md).
**Не возвращайте интерфейс в браузер как основной клиент.**

Статус `deprecated` означает «не развиваем», а не «удалено»: сборка цела и именно её
до сих пор выкладывает `npm run deploy`.

## Что осталось и в какой роли

| файл | строк | роль |
|---|---|---|
| `src/main.js` | 1406 | весь браузерный клиент: рендер, ввод, HUD, сумка, чат, частицы, сеть |
| `src/world.js` | | рендер мира поверх `world-core.js` |
| `src/tex.js`, `src/skin.js` | | пиксельные текстуры, нарисованные кодом |

Эти четыре файла — **только браузер**. Остальные модули `src/` (`data.js`, `stats.js`,
`sim.js`, `pvp.js`, `world-core.js`, а также `models.js` и `glb.js` для запекания моделей)
никуда не делись и по-прежнему несущие: их импортируют сервер, юнит-тесты и экспортёр в Godot —
см. [Общие правила](docs/gitmark/reference/shared-rules.md).

## Команды

| команда | что делает |
|---|---|
| `npm run dev:web` | Node-сервер + Vite на http://localhost:5173 |
| `npm run build:web` | сборка Vite в `dist/` |
| `npm run test:e2e` | Playwright-прогон `tests/e2e.mjs` (сам поднимает Vite на 5199, сервер на 8791) |
| `npm run test:web` | юнит + сервер + сборка + E2E |

`?ws=ws://…` задаёт адрес сервера, `?test` открывает тестовый хук `window.__g`.

## Чем это опасно

- **Браузерный клиент вышел из основного `npm test`.** Теперь `npm test` — это юнит + сервер +
  нативный smoke. Регрессия в `src/main.js` не будет поймана, пока кто-нибудь явно не запустит
  `npm run test:web`.
- **`npm run deploy` до сих пор выкладывает веб-`dist/`.** Раздача нативных сборок пока только
  план ([DISTRIBUTION.md](docs/DISTRIBUTION.md)), поэтому прод на https://realms.neuraldeep.ru —
  это именно эта, легаси-версия. Открытый хвост миграции, см.
  [план](docs/gitmark/plans/godot-migration.md).

## E2E, который стоит сохранить

[`tests/e2e.mjs`](tests/e2e.mjs) (431 строка) — самый подробный сценарий во всём проекте:
стартовый экран, создание персонажа, ходьба по клику, жесты камеры, покупка с монетами и без,
телепорт, убийство моба с опытом, две попытки читерства (подмена профиля в консоли и рывок
через полкарты), умения с маной и кулдауном, повышение уровня, перетаскивание по кукле,
безопасная заточка до +3, смерть и возрождение, склеп, свиток побега, выживание прогресса
после очистки localStorage, затем телефонный контекст (мобильный UI, раскладка iPhone 16,
джойстик) и мультиплеер с PvP (взаимная видимость, чат, шёпот, флаг → PK → объявление →
смывание кармы у жреца).

Часть этих сценариев в нативном клиенте покрыта `godot/tests/smoke.gd`, но не вся —
телефонная раскладка и жесты камеры пока живут только здесь.
